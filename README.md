# OpenConvo

**OpenConvo** is a simple, browser-based voice meeting application. It lets people talk online without creating an account or installing extra software.

## How It Works

1. A person selects **Start a Meeting**.
2. OpenConvo creates a unique **four-digit meeting code**.
3. The host shares this code with other people.
4. Participants enter their **name** and the meeting code to join.
5. Once connected, everyone can talk through their microphone in real time.

OpenConvo uses **WebRTC** to send high-quality voice audio directly between participants. **Socket.io** helps participants find the correct meeting room and connect with one another.

> A modern browser and microphone permission are required to use OpenConvo.

## Features

- **No account or login required**
- **Random four-digit meeting codes**
- **Real-time voice communication**
- **Multi-person voice meetings**
- **Mute and unmute microphone**
- **Simple black-and-white design**

## Built With

- **Node.js**
- **Express**
- **Socket.io**
- **WebRTC**
- **Vanilla HTML, CSS, and JavaScript**
